# ChatMuxX

一个让手机社交应用(Telegram、wechat)等能够连接电脑端Tmux的Codex、ClaudeCode进行编程开发等交互的程序。
很多地方可以参考ccgram的实现，但我们要更加模块化、更加自由好用。
