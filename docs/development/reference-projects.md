# Reference Projects

Status: reference only.

These projects helped shape ChatMuxX design and protocol understanding. ChatMuxX is a new implementation and does not depend on these projects at runtime.

## WeChat iLink

- npm: https://www.npmjs.com/package/@tencent-weixin/openclaw-weixin-cli
- GitHub: https://github.com/hao-ji-xing/openclaw-weixin
- Local reference path: `references/openclaw-weixin`

ChatMuxX uses this code only to understand Tencent iLink HTTP endpoints and message fields. The v0.1 implementation calls iLink HTTP directly.

## ccgram

- GitHub: https://github.com/alexei-led/ccgram
- Local reference path: `references/ccgram`

ChatMuxX uses ccgram as experience-level inspiration for mobile chat to tmux-agent workflows. ChatMuxX is not a ccgram fork.
